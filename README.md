# Clawfour Renovation Management (爪四装修)
A renovation project management platform with roles for homeowner, company, and admin.

## Features
- Complete project lifecycle tracking
- Phase and node management
- Material and comments tracking
- Activity logs
- Role-based views

## Development
```bash
npm install
npm run db:push
npm run db:seed
npm run dev
```

Next.js App Router, Tailwind, shadcn/ui inspired components, Prisma SQLite.
